## 6. Cara memakai tiap menu (langkah singkat)

### A. Beranda

1. Buka menu **Beranda**.  
2. Ubah **Headline**, **Deskripsi**, teks pendukung (opsional), dan **teks tombol** (CTA).  
3. Upload **foto portrait hero** dan **foto kotak konsultasi** (format JPEG / PNG / WebP, maksimal sekitar 5 MB).  
4. Klik **Simpan**.  
5. Buka https://legalsakinah.com untuk memeriksa hasilnya.

### B. Pengaturan (paling penting di awal)

1. Buka menu **Pengaturan**.  
2. Isi / perbarui: nama situs, tagline, motto, deskripsi singkat.  
3. Isi **nomor WhatsApp** dengan format internasional tanpa tanda `+` (contoh: `62812xxxxxxxx`).  
4. Isi **teks pembuka chat WhatsApp** (prefill) sesuai kebutuhan.  
5. Isi alamat kantor, jam operasional, dan email kontak.  
6. Isi tautan Instagram / Facebook jika ada.  
7. Kolom analytics (GA4 / Meta Pixel) boleh dikosongkan jika belum dipakai.  
8. Klik **Simpan pengaturan**.  
9. Tes tombol konsultasi di website dari HP.

### C. Layanan

1. Buka menu **Layanan**.  
2. Klik layanan yang ingin diubah, atau buat baru.  
3. Isi judul, ringkasan, isi lengkap, dan informasi harga jika ada.  
4. Atur **urutan tampil** (angka lebih kecil biasanya tampil lebih dulu di beranda).  
5. Klik **Simpan**.  
6. Set status **Tayang** agar tampil di publik.  
7. Cek di https://legalsakinah.com/layanan

### D. Tim

1. Buka menu **Tim**.  
2. Tambah atau edit anggota.  
3. Isi nama, jabatan/peran, dan deskripsi singkat.  
4. Upload foto.  
5. Atur urutan jika tersedia.  
6. Simpan, lalu set **Tayang**.  
7. Cek di https://legalsakinah.com/tim

### E. FAQ

1. Buka menu **FAQ**.  
2. Tambah atau edit pertanyaan & jawaban.  
3. Atur urutan jika perlu.  
4. Simpan dan set **Tayang**.  
5. Cek di https://legalsakinah.com/faq

### F. Testimoni

1. Buka menu **Testimoni**.  
2. Tambah atau edit kutipan, nama pemberi testimoni, dan foto (jika ada).  
3. Simpan dan set **Tayang**.

### G. Artikel

1. Buka menu **Artikel**.  
2. Buat artikel baru atau edit yang ada.  
3. Isi judul dan isi tulisan (bisa memakai format teks sederhana: tebal, daftar, tautan).  
4. Simpan sebagai **Draft** dulu jika masih diperbaiki.  
5. Setelah siap, set **Tayang**.  
6. Cek di https://legalsakinah.com/artikel

### H. Landing Pages (untuk iklan / promo)

1. Buka menu **Landing Pages**.  
2. Buat atau edit halaman khusus kampanye.  
3. Isi konten sesuai materi iklan.  
4. Simpan dan set **Tayang**.  
5. Salin tautan publik halaman tersebut untuk dipakai di iklan.  
6. Halaman yang masih Draft tidak bisa dibuka pengunjung.

### I. Halaman situs

1. Buka menu **Halaman situs**.  
2. Pilih halaman yang ingin diubah (misalnya **Tentang**, **Kontak**, atau kebijakan).  
3. Sesuaikan teks sesuai form yang tersedia.  
4. Simpan, pastikan status **Tayang**.  
5. Buka halaman publik terkait untuk memeriksa.

### J. Akun (ganti password)

1. Buka menu **Akun** (atau https://legalsakinah.com/admin/akun).  
2. Masukkan password saat ini.  
3. Masukkan password baru (dua kali untuk konfirmasi).  
4. Simpan.  
5. Simpan password baru di tempat aman.

**Catatan foto:** unggah lewat form di admin. Jika gambar lama tidak tampil, cukup upload ulang foto yang benar.
